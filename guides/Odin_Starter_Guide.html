2. Insightful timer and pay

How to run the timer

  1. Open Insightful (also called Workpuls) → sign in with your @mercor.expert account.
  2. Find Odin in the project list → press Play ▶. Check that the time counts up.
  3. Minimize it to the Dock (yellow button). Never open its window during a recording.
  4. Press Stop / Pause for breaks and when you finish for the day.
Run it for all real Odin work: reading the guide, setup, idea writing, preparing inputs, practice, recording, re-takes, uploading and submitting.
Don't run it: during breaks, idle time or non-Odin work.

If you record in a separate Mac user (recommended, see below), start Insightful in that user too.

Hourly pay is sent on Wednesday for the previous Saturday–Friday. Keep no more than 3 open tasks in Trial. Pay questions → Maven in #odin--helpdesk.

3. One-time Mac setup

Needs: Mac with Apple Silicon (M1 or newer) or Intel (use the Intel TaskRecorder build), macOS 15+, 35 GB+ free, plugged into power.

3.1 Separate recording user (recommended)

Studio now says a separate user isn't required, but it's the easiest way to keep personal info off screen.

  1. System Settings → Users & Groups → Add User → Administrator, neutral name like Recorder.
  2. Log in to it, skip iCloud, keep the language English.
  3. Keep Studio, Slack, the guidelines and Metadata.rtf in your main user. Record in the Recorder user.
  4. To move files between users, use the shared folder: Finder → Go → Go to Folder → /Users/Shared.

3.2 Clock, Dock and look (in the recording user)

  • Clock: System Settings → Menu Bar → Clock Options → turn on Display the time with seconds + show the date.
  • Dock: System Settings → Desktop & Dock → Position Left or Right (never Bottom), Automatically hide OFF, Show indicators for open apps ON.
  • Wallpaper: not personal and not the macOS default.
  • Do Not Disturb on. Remove desktop widgets. Clear personal files off the Desktop.
  • Mouse cursor: keep the default size and colour.

3.3 Accessibility Inspector (must run in every recording)

  1. Install Xcode from the App Store.
  2. Open Xcode → right-click Xcode in the Dock → Open Developer Tool → Accessibility Inspector.
  3. Close its window with the red button (don't quit, don't minimize). A dot must stay under its blue magnifying-glass icon in the Dock. You can quit Xcode.

3.4 TaskRecorder 2.4.4

  1. Download TaskRecorder2.4.4.dmg from World files on any Studio task.
  2. Open it → drag TaskRecorder into Applications → Replace if asked.
  3. Open it. If blocked: System Settings → Privacy & Security → Open Anyway.
  4. Turn on Accessibility, Screen Recording, Microphone until all 3 are green. If one stays red: remove TaskRecorder from that Privacy list with –, add it again with +, then quit and reopen.
  5. Choose the built-in display and mic Standard mode. Speak and check the meter goes green.
2.4.4 needs no login. If it asks you to sign in or for a password, you still have an old version.

4. The task workflow (start to finish)

  1. Idea: Studio → Tasks → + Create Task. Fill Describe your idea with 5 headings: Domain/Role, Goal, Starting materials, Steps (with the app for each step), Deliverable. Add the Apps (at least 3; 1–2 only for deeply technical work). Save Changes → Submit idea.
  2. Idea check: wait about 1 minute. If it's sent back, read the report, fix it, then Resubmit. The usual reason is that the apps named in the text don't match the Apps list.
  3. Approved: the same task becomes "Idea Approved: Start Recording". Don't create a second task.
  4. Inputs: prepare any starting files before recording. AI-made inputs must come from Gemini only, with no real personal data and only CC0/public-domain media.
  5. Goal document: if Studio's Intro doc is empty, paste the approved Goal into a doc → download as PDF → open it in Brave at the start of the recording.
  6. Metadata.rtf (main user only): download the template from the task and fill in Topology (e.g. VS Code (MODIFY) -> Bruno (CREATE) -> DB Browser (LOOKUP)), Request (the Goal, word for word) and Task Description (a numbered list). Delete the red example section. TextEdit is allowed only for this file.
  7. Practise the whole task once without recording, then reset everything to the start.
  8. Record (section 6) → check → upload and submit (section 8).

6. Recording: step by step

Before pressing Start

  1. Insightful running and minimized. Mac plugged in. Do Not Disturb on. Quiet room.
  2. Change at least one UI element from your last recording: wallpaper, light/dark mode, accent colour, Dock size or similar.
  3. Accessibility Inspector dot visible.
  4. Open every task app, log in, load the files, set each window to Fill, then minimize them all. Don't do any task work yet.
  5. Quit everything else: chats, Slack, extra browser tabs, Terminal, Messages.
  6. Open the Goal PDF in Brave (Fill). It should be the only window, behind TaskRecorder.
  7. TaskRecorder: paste the Goal (exactly as approved) into Task Description, add every task app under Used Apps, check that all 3 permissions are green and the mic meter moves.

During

  1. Click Start Recording → immediately minimize TaskRecorder (yellow button).
  2. With the Goal doc visible, say only: "I will be beginning my task soon. Here is the workflow I have in mind." Keep the intro under 20 seconds. Don't read the Goal aloud.
  3. Minimize the Goal doc → open your first app from the Dock → do the task in one take. There is no pause button.
  4. Small mistake? Say what went wrong, fix it, check it and carry on. Big mistake? Stop and re-record.
  5. Save every output.
  6. Epilogue, 3–4 minutes (max 4:00): how you checked the result, your approach, challenges, quality, and what you'd do differently. Required for ideas approved on or after 19 Oct.
  7. Click TaskRecorder in the Dock → Stop Recording → don't quit. Wait for Stopping → Archiving → Idle.

7. How to narrate

Talk so that someone with their eyes closed could follow. Priority order: WHAT you do → WHERE it is on screen → WHY (when it explains a decision).

Good: "I'm moving to the Dock on the right side and clicking the blue VS Code icon. In the File menu at the top, next to the word Code, I click Save. The dot on the tab disappears, so it's saved."
Bad: "I'll click this here and fix that."
  • For every click, say where it is (corner, side, next to what), what it's called, and what happens after ("a menu appears", "it turns blue").
  • Point the cursor at whatever you're talking about.
  • Say every keyboard shortcut before you press it ("I'm pressing Command S to save").
  • While typing, say what you're writing and stop every few lines to explain it.
  • 100% English. No profanity. No personal information said aloud.
  • Don't read a script word for word. Practise until you can say it naturally.

8. After recording: files and submit

  1. TaskRecorder → Show Recordings → open the newest recording_TIMESTAMP folder.
  2. Play video.mp4 in QuickTime: check the start, middle and end for a clear picture and audible voice.
  3. Count the PNGs in screenshots (Finder → View → Show Status Bar shows "N items"). You need more than 0.5 × video seconds. Count every PNG in that folder.
  4. Make deliverables.zip. Name each file by what it is and keep the extensions: 
    input 1, input 2 ...          starting files you prepared
artifact 1, artifact 2 ...    in-between files made during the task
final output 1, final output 2 ...   the finished results
(for a code project: put the whole project in a folder named "final output 1")
  5. Copy deliverables.zip, recording_TIMESTAMP.zip (unchanged) and video.mp4 to /Users/Shared, then switch to the main user.
  6. Studio → your task → upload the 4 files, each in its own field: Metadata.rtf, video.mp4, recording zip, deliverables.zip. Metadata.rtf never goes inside the zip.
  7. Run AutoQC 1 (Files & Recording) and AutoQC 2 (Narration). Fix or dispute Major flags. Minor flags are advice only.
  8. Tick the manual checks only after really checking the video, tick the confirmation boxes, and add a Final note (e.g. Input 1 was AI-generated before recording.).
  9. Click Submit for Review → status becomes Ready for Review. Watch for feedback in My tasks.

9. Apps: allowed and banned

  • Check every app in the Apps list on the task, and on the validated-apps page linked there. Anything marked 🚫 RESTRICTED cannot appear at all, not even briefly.
  • Banned examples: Excel (use Google Sheets instead), Keynote, Pages, Numbers, Preview, Terminal app, iMovie, Final Cut Pro, Logic Pro, Calendar, Reminders, LibreOffice Calc/Writer/Impress, Adobe Acrobat. TextEdit only for Metadata.rtf.
  • Now allowed (since 22 Oct): Safari and Chrome. Other browsers such as Brave or Firefox are still preferred.
  • Finder, the Goal document app and Insightful don't count as task apps.
  • No AI features during recording. Turn off Copilot and AI chat panels in apps like VS Code and DBeaver. Normal autocomplete is fine.
